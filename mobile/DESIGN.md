# PBVF Mobile — Design system

Aligné site web (`#0a0e27`, or `#f3ac41`). Mode **Operate**.

## Formes

| Token | Valeur | Usage |
|-------|--------|--------|
| `radius.card` | 12px | cartes, tuiles, listes |
| `radius.chip` / `button` | 8px | filtres, CTA |
| Surfaces | fond seul | pas bordure + teinte + ombre empilés |

## Typographie

- **Urbane Bold** — un titre de marque par écran (hero, nom live, titres de page)
- **Inter** — corps, labels, boutons, tab bar, chips
- Pas de uppercase forcé ni tracking > 0.5 sur l’UI

## Composants

- `GlassCard` — surface plate
- `PrimaryButton` — Inter, rayon 8px, sans glow
- `PbvfTabBar` — icônes uniformes, point actif, pas de cercle flottant
